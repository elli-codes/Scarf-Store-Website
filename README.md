# Scarf-Store-Website
A Persian-language fashion website designed to showcase and present a variety of scarves and shawls through an elegant and visually appealing online catalog.

The website focuses on product presentation, seasonal collections, and providing visitors with an easy way to explore different scarf styles and collections.

✨ Project Overview

This project is a front-end website for a scarf store, featuring multiple pages dedicated to different product collections and seasonal styles.

The website is designed to provide a simple and user-friendly browsing experience while highlighting product images and collection categories.

🚀 Features: 

Product Showcase: Displaying a variety of scarves and shawls through product images.

Seasonal Collections: Separate sections for different seasonal collections.

Spring Collection: Showcasing spring-inspired scarf designs.

Summer Collection: Featuring lightweight and summer-style scarves.

Autumn Collection: Presenting autumn-inspired designs and styles.

Product Gallery: Visual presentation of products to help visitors explore available designs.

Persian Language Support: Website content designed for Persian-speaking users.

RTL Layout: Right-to-left page structure for Persian content.

Multiple HTML Pages: Separate pages for different collections and website sections.

Custom Styling: Individual CSS stylesheets for page layouts and visual presentation.

Order & Representation Section: A dedicated section for order inquiries and dealership opportunities.
